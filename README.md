## 🚀 Featured Projects

### 🎯 TrendCipher — AI-Powered YouTube Trend Analysis (Any Language → Always English)

**TrendCipher** is an end-to-end AI-powered YouTube video analysis platform. Paste any YouTube URL — in Hindi, Marathi, Korean, Spanish, Turkish, Arabic, or 50+ other languages — and TrendCipher instantly delivers:

- 📄 A structured **English summary**
- 📊 **Engagement metrics** & analytics
- 💬 **Sentiment breakdown**
- 📈 **Trend score**
- 🔑 **Key topic extraction**

Built using a **multi-agent AI pipeline** with **CrewAI, Ollama (LLaMA 3), BrightData, and Streamlit**.

`Python` `CrewAI` `Ollama / LLaMA 3` `BrightData` `Streamlit`

---

### 🛡️ RoverLog — AI-Powered Portable Log Analysis & Threat Detection Platform

Built for **Smart India Hackathon 2025** | Problem Statement: *Portable Log Analysis Tool for Isolated Networks*

A lightweight, AI-driven platform designed to analyze system logs and detect security threats — even in **air-gapped / isolated network environments** where cloud-based tools can't reach.
